# Service artwork

`pubg-hero.png`: generated for this store using the built-in imagegen tool, 24 September 2026. The PUBG wordmark is rendered separately in HTML.

Brand SVG glyphs: Simple Icons, downloaded from `https://cdn.simpleicons.org/{slug}`. OpenAI: `https://raw.githubusercontent.com/simple-icons/simple-icons/14.0.0/icons/openai.svg`. Simple Icons distributes its icons under CC0; names and marks belong to their owners. These files are bundled locally and do not contact a third-party CDN at runtime.

An image uploaded for a service in the admin editor takes precedence over this fallback artwork. Catalog prices, availability, names and payment accounts remain the source of truth.
