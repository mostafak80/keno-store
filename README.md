# Keno Store — متجر كينو للخدمات الرقمية (منصة التجارة الإلكترونية الاحترافية)

منصة ويب متطورة وشاملة للخدمات الرقمية، تدعم اللغة العربية (RTL) بالكامل، مبنية بمعمارية نقية وعالية الأداء (HTML5 / CSS3 / Vanilla JavaScript ES2022) **بدون الحاجة لأي أدوات بناء أو تجميع (Zero-Build Vanilla Architecture)**، ومصممة لتعمل **بشكل مجاني تمامًا وبصفر تكلفة شهرية دائمًا (Zero Monthly Cost)** عبر Cloudflare Pages أو GitHub Pages، مع قاعدة بيانات سحابية لحظية ومصادقة Google عبر Firebase Free Spark Plan.

---

## 💰 متطلبات التكلفة (مجاني 100% دائمًا)

تم تصميم النظام ليعمل بالكامل ضمن الخطط المجانية الدائمة:
- **الاستضافة**: Cloudflare Pages / GitHub Pages (مجاني، نطاق ترددي غير محدود، شهادة SSL تلقائية).
- **قاعدة البيانات السحابية**: Firebase Cloud Firestore (باقة Spark المجانية: 50,000 قراءة و 20,000 كتابة يوميًا).
- **المصادقة وتسجيل الدخول**: Firebase Authentication + Google Sign-In (مفتوح ومجاني بدون حدود للمشرفين).
- **المرونة المحلية (Graceful Degradation)**: يعمل المتجر تلقائيًا بكفاءة 100% باستخدام قاعدة بيانات `IndexedDB` المحلية ورموز الأمان المشفرة (Passcodes) حتى في حال عدم تهيئة Firebase أو انقطاع الإنترنت.
- **ضغط ومعالجة الصور**: معالجة محلية داخل متصفح العميل عبر HTML5 Canvas WebP (< 40KB) دون استهلاك أي خوادم مدفوعة.

## 🚀 المميزات الرئيسية للمنصة

### 1. نظام إدارة ومتابعة الطلبات (Real-Time Order Management)
- توليد معرّف طلب فريد لكل عملية شراء (مثال: `#KENO-4819`).
- حفظ تفاصيل الطلب كاملة (الاسم، الهاتف، الحساب، المنتجات، الإجمالي، طريقة الدفع، صورة الإيصال، التاريخ، والملاحظات) في قاعدة بيانات Firestore السحابية فورًا مع نسخة احتياطية في IndexedDB.
- **دورة حياة وحالات الطلب (Order Lifecycle)**:
  - `pending` (قيد الانتظار) — اللون الكهرماني.
  - `paid` (تم التحويل / مدفوع) — اللون الأزرق.
  - `processing` (جاري التنفيذ) — اللون البنفسجي.
  - `delivered` (تم التسليم بنجاح) — اللون الزمردي الأخضر.
  - `cancelled` (ملغي) — اللون الوردي / الأحمر.
- إمكانية تغيير حالة الطلب بنقرة واحدة من الجدول أو من داخل نافذة الفحص الشاملة (`#orderDetailsDialog`).
- فلترة وتصفية سريعة للطلبات بحسب الحالة أو بالبحث بالاسم ورقم الهاتف ورقم الطلب.

### 2. لوحة الإحصائيات الحيوية (Admin KPI Overview)
- **إجمالي الطلبات**: إجمالي العمليات المسجلة.
- **قيد الانتظار**: الطلبات الجديدة التي تتطلب مراجعة أو تسليم.
- **تم التسليم**: الطلبات المنفذة بنجاح.
- **إجمالي المبيعات**: حساب دقيق لحجم الإيرادات بالجنيه المصري (EGP).
- **الخدمة الأكثر طلباً**: استنتاج تلقائي لأعلى خدمة مبيعاً في المتجر.

### 3. المصادقة الآمنة وحماية الإدارة (Authentication & RBAC)
- **دخول المشرفين عبر حساب Google**:
  - يتم التحقق من البريد الإلكتروني عبر القائمة البيضاء (`KenoConfig.AUTHORIZED_ADMINS` أو مجموعة `users` في Firestore).
  - يُحظر أي بريد غير معتمد فورًا ويتم تسجيل خروجه لمنع الوصول.
- **نظام الصلاحيات المتعدد (RBAC)**:
  - **المالك (Owner)**: تحكم شامل، إدارة المدفوعات، إعدادات المتجر، نشر التعديلات على GitHub، ومسح السجلات.
  - **محرر المحتوى (Editor)**: إضافة وتعديل الخدمات والأسعار والباقات والبطاقة المميزة دون صلاحية النشر المباشر.
  - **المراجع (Viewer)**: فحص الطلبات وتصفح المسودات في وضع القراءة فقط (Read-Only).
- مؤقت أمان تلقائي يقفل اللوحة بعد 60 دقيقة من الخمول للحماية.

### 4. إدارة طرق الدفع المرنة (Payment Methods Manager)
- دعم كامل لـ: **Vodafone Cash** و **InstaPay** و **Telda** وأي وسيلة دفع مخصصة.
- إمكانية إضافة، تعديل، وتفعيل/تعطيل طرق الدفع، تغيير الحسابات وأرقام المحافظ وروابط الدفع المباشرة.
- لا تظهر للعميل إلا وسائل الدفع المفعّلة (`enabled: true`).

### 5. تجربة الدفع الاحترافية في 5 خطوات (5-Step Checkout Experience)
- **الخطوة 1**: مراجعة السلة والكميات وتفاصيل الباقات.
- **الخطوة 2**: إدخال بيانات العميل (الاسم، رقم الهاتف/واتساب، ومعرف الحساب أو ID اللعبة).
- **الخطوة 3**: اختيار وسيلة الدفع المناسبة ونسخ رقم التحويل أو فتح رابط الدفع المباشر.
- **الخطوة 4**: رفع سكرين شوت إثبات التحويل مع ضغط الصورة تلقائيًا وتوفر إمكانية المعاينة والاستبدال.
- **الخطوة 5**: تأكيد الطلب وحفظه في السحابة وفتح محادثة واتساب المنظمة بنقرة واحدة.

### 6. رسائل واتساب المعيارية (Standardized Notifications)
توليد رسالة عربية دقيقة ومضبوطة الترميز بالصيغة:
```text
مرحبًا Keno Store 👋

طلب جديد 🛒

رقم الطلب: {orderId}

🎮 الخدمة: {serviceName}
📦 الباقة: {planName}
💰 السعر: {price}

💳 الدفع: {paymentMethod}
📎 تم إرفاق إثبات التحويل مع الطلب

برجاء تأكيد الطلب والبدء في التنفيذ ✅
```

### 7. التحكم في الواجهة والشبكات الاجتماعية
- لوحة إدارة البطاقة الترويجية البارزة في الهيدر (Hero Featured Card) مع معاينة حية لحظية.
- إدارة روابط وتفعيل أزرار المنصات: **Facebook** و **Instagram** و **TikTok** و **Telegram**.

## 🛡️ قواعد أمان Firestore (`firestore.rules`)

توجد القواعد في ملف `firestore.rules` وهي معدّة للنشر مباشرة:
1. **الطلبات (`orders`)**:
   - يُسمح لأي عميل بإنشاء طلب جديد بشرط احتوائه على الحقول الأساسية وتكون حالته الابتدائية إجبارياً `pending`.
   - لا يمكن قراءة الطلبات أو تعديل حالتها أو حذفها إلا للمشرفين المعتمدين المسجلين في القائمة البيضاء.
2. **المستخدمون (`users`)**:
   - لا يمكن تعديل صلاحيات المشرفين إلا للمالك (`Owner`).
3. **الخدمات وطرق الدفع والإعدادات**:
   - قراءة عامة للزوار، وتعديل محمي للمحررين والمالكين.

## ⚙️ دليل تهيئة Firebase السحابي (Spark Plan مجانًا)

1. توجه إلى [Firebase Console](https://console.firebase.google.com/) وأنشئ مشروعًا جديدًا (اختر اسماً مثل: `keno-store`).
2. قم بتفعيل **Authentication**:
   - من القائمة الجانبية: **Build** &rarr; **Authentication** &rarr; اضغط **Get Started**.
   - من علامة تبويب **Sign-in method**: فعّل **Google**.
3. قم بتفعيل **Cloud Firestore**:
   - من القائمة الجانبية: **Build** &rarr; **Firestore Database** &rarr; اضغط **Create Database**.
   - انسخ محتويات ملف `firestore.rules` والصقها في تبويب **Rules** ثم اضغط **Publish**.
4. أضف تطبيق ويب (Web App):
   - من إعدادات المشروع (Project Settings) &rarr; أضف تطبيق Web واحصل على مفاتيح التكوين (`firebaseConfig`).
5. تفعيل الربط في متجر كينو:
   - افتح لوحة إدارة كينو (`#admin`) &rarr; انتقل إلى تبويب **إعدادات المتجر**.
   - في قسم **ربط سحابة وقاعدة بيانات Firebase المجانية**، أدخل المفاتيح واضغط **حفظ بيانات Firebase وتفعيل السحابة**.
   - ستتحول الشارة فورًا إلى `متصل بالسحابة ✓` وتبدأ المزامنة اللحظية للطلبات!

## 👨‍💻 دليل المطوّرين (Developer Maintenance)

### إضافة مشرف جديد معتمد
في ملف `js/config.js`، أضف البريد الإلكتروني للمشرف في مصفوفة `AUTHORIZED_ADMINS`:
```javascript
AUTHORIZED_ADMINS: [
  { email: 'owner@example.com', role: 'owner' },
  { email: 'editor@example.com', role: 'editor' },
  { email: 'viewer@example.com', role: 'viewer' }
]
```
أو أضف مستندًا في مجموعة `users` في Firestore باسم بريده الإلكتروني مع حقل `role`.

### إضافة أو تعديل خدمة برمجياً
في ملف `assets/catalog.js`، أضف كائن الخدمة في مصفوفة `services`:
```javascript
{

  "name": "اشتراك بلايستيشن بلس",
  "category": "gaming",
  "description": "اشتراكات PlayStation Plus الأساسية والإضافية لحسابات الشرق الأوسط وأمريكا.",
  "mark": "PS PLUS",
```
